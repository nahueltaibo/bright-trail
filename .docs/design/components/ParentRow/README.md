# ParentRow

One line in a parent list: an optional leading avatar or icon, a title, a meta line, and a trailing badge, button or chevron.

Provide `title`, optional `meta`, `leading`, `trailing`, `chevron` (makes it a button), `onClick`, `action` (primary-coloured, for "Add a child").

- At least 64px tall. Meta in `p-meta`, `p-ink-muted`.
