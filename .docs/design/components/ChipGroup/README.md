# ChipGroup

Single-choice chips, used for the school grade.

Provide `label`, `options` (strings or `{ value, label }`), `value`, `onChange`, optional `hint`.

- Selected chip: check icon, 2px `p-primary` border, `p-primary-soft` ground.
- The first grade chip is "Auto (Grade N)" from the birthdate. Choosing another grade marks the child "set by parent".
