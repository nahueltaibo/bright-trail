# FlagButton

"This looks wrong": a quiet flag that turns into "Thanks for telling us" once tapped.

Provide `onFlag` to record the flag with the card's content id. Pass `flagged` to start in the thanked state.

- Top-right on story cards and item screens. It is for grown-ups and older kids, so it uses the `quiet` look and never animates.
- After the tap it stays thanked for that card. There is no undo here. Parents resolve flags in Flagged content.
