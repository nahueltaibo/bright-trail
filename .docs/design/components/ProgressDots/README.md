# ProgressDots

Where you are in a story or a check, shown as dots.

Provide `total`, `current` (0-based), optional `variant: 'steps'` (bigger, for checks and reviews) and `noun` for the spoken label.

- Current is a wide `trail-deep` pill, done dots are filled, the rest are rings: shape carries position, not colour.
- It shows position only. Never mark right or wrong on it.
