# ScreenPlacement

Placement uses the item screens but feels like exploring, not a test.

- Never say test, quiz, score or level. Say explore, puzzles, find your spot.
- No progress bar: placement is adaptive and its length is unknown. A pause button sits top-centre instead.
- Paused: "Good stopping spot!" Placement can span two sessions.
- End: the trail appears with the avatar on its first open stop. No score, no count of right answers.
