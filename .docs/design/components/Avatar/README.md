# Avatar

One of the eight animal avatars, drawn from emoji on a soft disc.

Provide `animal` (`fox owl penguin frog lion unicorn octopus dinosaur`) and `size` (a CSS length; default 64pt scaled). Set `decorative` when a name sits next to it.

- Discs use `av-peach`, `av-mint`, `av-sky`, `av-lilac`. The pairing is fixed per animal so a child learns their colour.
- Leave room for illustrated avatars later: keep the disc and swap the emoji for an image of the same size.
