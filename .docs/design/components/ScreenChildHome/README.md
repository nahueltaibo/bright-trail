# ScreenChildHome

The child's home: a greeting with their avatar, their trail, and one big start action.

- Returning: Start goes to the next stop's story.
- Brand new: a single "Start here" stone and "Let's go", which opens placement.
- Review due: the button becomes "Quick review" with the circular arrow. The review runs before the next skill.
- Home (top-left) returns to the profile picker. The star count sits beside Start, never a streak.
