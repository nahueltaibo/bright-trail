# AvatarTile

The profile picker tile: a big avatar with the first name as a small caption.

Provide `animal`, `name`, `onClick`. Optional `size` for the avatar (default 112pt scaled).

- The picture is the button. The name is a caption for grown-ups and is not needed to choose.
- Spoken as "Maya, the penguin".
- Two columns on phones, up to five on tablets.
