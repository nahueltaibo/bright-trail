# Button

The parent zone button: calm, rectangular, text first.

Provide `children` (the label), optional `icon`, `variant` (`primary`, `secondary`, `secondary-danger`, `danger`, `link`), `small`, `full`, `disabled`.

- One `primary` per screen: Save, Add a child.
- `danger` appears only inside an open `ConfirmButton`. The closed state uses `secondary-danger`.
- 48px tall (`tap-parent`), `radius-sm`. Sentence case, verbs first.
