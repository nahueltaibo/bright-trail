# Logos

- `mark.svg`: the app mark, a trail winding up to a star, in a rounded square. Full colour only.
- `logo.svg`: mark plus wordmark for light grounds (`kid-bg`, `p-bg`, white).
- `logo-dark.svg`: the same lockup for dark grounds. Its wordmark is `kid-ink` and `trail-deep` from the dark theme.
- `wordmark.svg`, `wordmark-dark.svg`: the name alone, for places where the mark already shows nearby.

Every file is outlined, so it needs no font. Inks are fixed in the files and don't inherit `currentColor`.
