BrightTrail — Minigames

Which items play as minigames, which don't, and the plan to cover them · Draft v0.1 · 2026-11-11

553 of the 795 bundle items (70%) still play on the plain tap, keypad, or number-line screen. Six groups of them have no minigame that fits. The plan first makes adding a minigame a matter of one schema, one stage, and one tagger module, then builds the new games in order of how many items they cover.

The app side is already shared. GameFrame owns the prompt, answers, play-out, and feedback, and useGameProps turns any item into its props. What isn't shared:

  • Three optional item fields. ItemView picks scene, then slices, then join, so an item tagged twice plays one game without warning.
  • check-bundle.ts names each game's problem check by hand.
  • The four tag-*.ts scripts are copies that differ only in names.
  • One dev page per game: /dev/share, /dev/slices, /dev/join.

3. Foundation

Do these first, so each new game adds files instead of touching the item schema, ItemView, and the bundle check.

StepChange
One game fieldReplace scene, slices, and join with item.game, a union on kind. The scenes already carry kind. A shared registry of { schema, problems } drives check-bundle.ts. Bump schemaVersion. No native change, so it ships over the air.
App registryOne map from kind to Game component. ItemView looks it up. One dev route, /dev/games/[kind], plays each game's demo.ts.
One taggercontent:games -- --kind <kind> runs a per-game module { candidates, request, accept, file }. Each game keeps its own reviewed file, such as content/join.json. LLM cache keys stay the same, so reruns stay free. The old npm scripts stay as aliases.

0Retag existing gamesunknownJoin already goes to 20 but tags few items in g1-mental-math-20 and g2-add-sub-facts-20. Sharing has groups and total asks but barely tags multiplication skills.
1Compare and order~117Up to 20, cube towers stand side by side. Above 20, and for fractions and decimals, flags drop onto a number line and the rightmost wins. Sets the pattern the later games follow.
2Base-ten blocks~94Flats, rods, and cubes build a number. Asks: read it, a digit's worth, expanded form, trade 10 ones for a ten. Later carries regrouping for g1-add-sub-problems-50.
3Arrays~94Things fill rows and columns. Asks: total, rows, per row, turn the array, split it. Reuses ThingArt.
4Hundred grid~80A 10 × 10 grid or a tenths strip fills in. Asks: read it as a decimal, fraction, or percent, and find equal amounts.
5Stepping stones~45The frog hops stones by a fixed step, and one stone is missing. Builds on hops.ts and the number-line art.

The "Other" group stays on the plain screens for now. An ordinal line-up game could take the ~12 "Seventh place" items later.
