## Reviewer Changes

### Kindergarten

I checked all 13 Kindergarten skills for needed, direct, and missing prerequisites, for pointers to later grades or to themselves, and for title and description fit. No prerequisite is redundant: no listed prerequisite depends on another listed one, and there are no cycles or forward references. All prerequisite ids exist in the prompt. Counting-based prerequisites (k-count-to-20 in k-more-less-same and k-equal-share) are left as is, since counting is the expected strategy at this grade and the link is defensible. The k-make-numbers-to-10 title is narrower than its description but is not wrong, so I did not change it.

- `k-add-sub-stories-10`: The description and the A6.12 expectation both include compare stories ("Who has more? By how much?"). A kid cannot solve those without understanding more and less, and no other listed prerequisite (k-add-sub-facts-5 depends only on k-make-numbers-to-10) provides that, so k-more-less-same is a missing direct prerequisite.
- `k-coins-and-bills`: The symbols 25¢ and $10 do not read aloud reliably. Spelling out "25 cents" and "10 dollars" suits a kid hearing the description read aloud and keeps the same meaning.
- `k-read-write-numbers-20`: The A6.3 expectation is to identify and write numbers to 20. The description says "type", which describes a different activity and does not match the expectation. Changing it to "write" aligns the description with the expectation.

### Grade 1

I checked all 13 Grade 1 skills for unneeded, indirect, or missing prerequisites, forward or self references, and kid-friendly wording. All prerequisite ids exist in the prompt, and none point to a later grade or to the skill itself. Corrections were made only where a listed prerequisite is clearly unneeded or a needed one is missing, plus one title whose wording is ambiguous when read aloud. Items I judged acceptable and left alone: g1-count-50 in g1-equal-groups and g1-estimate-50 (skip counting by 2s, 5s, and 10s), g1-add-sub-facts-10 (k-make-numbers-to-10 is already covered through k-add-sub-facts-5), and g1-compare-unit-fractions (g1-half-equals-two-fourths is needed for comparing halves and fourths). Fixing the ordering skill leaves the rest of the chain consistent.

- `g1-compare-order-50`: Putting numbers up to 50 in order depends on knowing the counting sequence up to 50 (which number comes next, and where each number sits on a number line or hundred chart). That is taught in g1-count-50, which is not listed. It is a direct need, not covered by any other listed prerequisite, so it should be added.
- `g1-add-sub-problems-50`: The skill is solving stories up to 50 with pictures, number lines, and equations, and finding the missing number. A kid can do this without mental math strategies for sums to 20, so g1-mental-math-20 is not a true prerequisite and should be removed. The remaining prerequisites are needed: the inverse relationship for finding missing numbers (g1-add-sub-properties), composing and decomposing tens and ones to work with numbers to 50 (g1-compose-decompose-50), and the story-problem idea from Kindergarten (k-add-sub-stories-10).
- `g1-add-sub-properties`: Read aloud, the title 'Order, zero, and checking' sounds like the ordering-numbers skill (g1-compare-order-50, 'Compare and order to 50'). The skill is about the commutative property (adding in any order), so 'Any order' says what the skill teaches and avoids confusion.
